# Pocket Combats Remaster — дизайн-документ

Рабочая версия. Описывает, во что превращается прототип: пошаговая RPG-гриндилка снаряжения в браузере (мобильный экран — главный), тёмный интерфейс, своя графика. Оригинальный Pocket Combats — источник духа (текстовый лог боя, локации, NPC), система снаряжения — по мотивам Evil Hunter Tycoon (разбор: `docs/research/eht-gear.md`).

Пометки: **[MVP]** — делаем в текущей итерации, **[позже]** — заложено в данных/архитектуре, но не реализуется сейчас.

## 1. Игровой цикл

```
Охота в зоне ──► лут (золото, вещи, материалы) ──► сумка
     ▲                                               │
     │        надеть / сравнить / разобрать / продать │
     │                                               ▼
 сильнее ◄── заточка, ранги, перековка, крафт ◄── кузница и чародейка
```

- Бой короткий (5–10 ходов), есть **автобой** и ускорение — гринд не должен утомлять руками.
- Каждая вещь — лотерея: база × качество × редкость × набор аффиксов × значения аффиксов. «Идеальная» вещь практически недостижима, «чуть лучше» находится постоянно.
- Прогресс идёт по трём осям: уровень персонажа, уровень зоны (уровень вещей), вложения в вещь (заточка, ранг, перековка).

## 2. Классы [MVP]

| Класс | Оружие | Левая рука | «Свой» материал брони | Ресурс | Роль |
|---|---|---|---|---|---|
| **Воин** | меч, булава, топор (одноручные) | щит | латы | Ярость | живучесть, блок, контратаки |
| **Берсерк** | двуручный меч, двуручный топор | — | латы | Ярость | большой урон, вампиризм, риск |
| **Охотник** | лук, арбалет | — (двуручное) | кожа | Энергия | криты, скорость, уклонение, яд |
| **Маг** | посох (двуручный) или жезл | сфера (к жезлу) | ткань | Мана | стихийный урон, контроль, щиты |

Броню любого материала и аксессуары (амулет, кольца, пояс) носят все; «свой» материал класса просто падает ему вдвое чаще (см. §4.2.1).

**Ресурсы вместо тактик.** Тактики оригинала убраны. Приёмы стоят ресурс и имеют перезарядку в ходах.
- Ярость (воин, берсерк): 0–100, +12 за нанесённый удар, +8 за полученный, в начале боя 0.
- Энергия (охотник): 0–100, +25 в начале каждого хода, старт 50.
- Мана (маг): запас = 20 + 4×Интеллект + бонусы, +реген за ход, старт полный.

## 3. Характеристики

### 3.1 Основные (распределяются: 3 очка за уровень)

| Стат | Что даёт |
|---|---|
| **Сила** (СИЛ) | +2 физ. атаки (мечи, топоры, булавы), +0.5% крит. урона |
| **Ловкость** (ЛОВ) | +2 физ. атаки луками, +3 точности, +3 уклонения, +1 скорости за 2 очка |
| **Интеллект** (ИНТ) | +3 маг. атаки, +4 маны, +0.2 регена маны |
| **Живучесть** (ЖИВ) | +12 здоровья, +1 защиты, +0.2% блока со щитом |
| **Удача** (УДЧ) | +0.3% шанса крита, +0.5% находки предметов, +1 точности |

### 3.2 Боевые (из статов, вещей, пассивок)

**Рост чисел с уровнем.** Здоровье, атака, защита и урон растут на 12% за уровень (×1 на 1 уровне, ×2.8 на 10, ×8.6 на 20, ×47 на 35). Персонаж растёт по своему уровню, база вещи — по уровню своего тира, монстры — чуть медленнее (показатель 0.93). Плоские свойства вещей растут как корень из множителя, процентные не зависят от уровня — поэтому к поздней игре проценты решают всё больше: идеальная сборка сильнее случайной того же качества в 1.3 раза на 11 уровне и в 2–5 раз на 28–36 (tools/compare.js).

Все ключи — в коде `stats.js`, вещи и пассивки складываются в один объект.

| Ключ | Название | Формула в бою |
|---|---|---|
| `atk` / `atkPct` | Физическая атака | урон = (оружие + atk) × (1 + atkPct) |
| `matk` / `matkPct` | Магическая атака | урон заклинаний = (база + matk) × (1 + matkPct) |
| `def` / `defPct` | Защита | множитель урона = 100 / (100 + def) |
| `mdef` / `mdefPct` | Маг. защита | то же для магии |
| `hp` / `hpPct` | Здоровье | |
| `crit` | Шанс крита | макс. 75% |
| `critDmg` | Крит. урон | база 150% |
| `acc` / `eva` | Точность / Уклонение | попадание = 85% + (acc − eva) × 0.2%, от 30% до 99%; магия не промахивается |
| `speed` | Скорость | порядок хода; шанс доп. действия = (свою − чужую) / чужую × 50%, макс. 35% |
| `block` | Блок (только со щитом) | заблокированный удар — 50% урона |
| `lifesteal` | Вампиризм | % от нанесённого урона |
| `hpRegen` / `mpRegen` | Восстановление за ход | |
| `cdr` | Сокращение перезарядки | −1 ход за каждые полные 25% (макс. 50%) |
| `dmgReduce` | Снижение получаемого урона | макс. 50% |
| `thorns` | Шипы | урон атакующему за каждый удар ближнего боя |
| `vsBeast`, `vsUndead`, `vsGoblin`, `vsHuman`, `vsConstruct` | +% урона по типу врага | |
| `fireDmg`, `coldDmg`, `poisonDmg` | Доп. стихийный урон к ударам | режется сопротивлением цели |
| `fireRes`, `coldRes`, `poisonRes` | Сопротивления | макс. 75% |
| `stunChance`, `bleedChance`, `chillChance` | Шансы эффектов при ударе | |
| `skillLvl.<id>`, `allSkills` | +уровень умения / всех умений класса | |
| `skillDmg.<id>` | +% урона умения | |
| `expPct`, `goldPct`, `mf` | Бонус опыта, золота, находки предметов | |

## 4. Предметы [MVP]

### 4.1 Слоты (10)

Оружие · Левая рука · Голова · Тело · Руки · Ноги · Пояс · Амулет · Кольцо ×2

### 4.2 Базы и тиры

- Типы баз: оружие — меч, булава, топор, двуручный меч, двуручный топор, лук, арбалет, посох, жезл; левая рука — щит, сфера; броня — 4 материала × 5 вариаций для головы, тела, рук и ног (§4.2.1); пояс, амулет, кольцо — по 5 вариаций.
- У каждого типа **7 тиров** (по зонам): «Ржавый меч → Короткий меч → Палаш → Рунный клинок → …». Тир задаёт базовые характеристики и требуемый уровень.
- **Уровень вещи (ilvl)** = уровень монстра, с которого она упала. От ilvl зависят тир базы и доступные тиры аффиксов.

### 4.2.1 Материалы брони

Идея: выбор брони — компромисс, а не «лучшая вещь для класса». Ограничения брони по классу нет, у материала свой плюс и минус, а смена комплекта — способ подготовиться к конкретному боссу. Доля защиты слота: голова 0.45, тело 1, руки 0.3, ноги 0.35 (от «полной» защиты доспеха тира).

| Материал | Защита / маг. защита | Плюс | Минус | Для кого |
|---|---|---|---|---|
| **Латы** | 1.0 / 0 | +% здоровья | −скорость, −% маг. атаки («мешают колдовать») | воин, берсерк; любой — против физических боссов |
| **Кожа** | 0.55 / 0 | +скорость, +шанс крита | −% маг. защиты | охотник; быстрый фарм |
| **Ткань** | 0.5 / 0.65 | +% маг. атаки | −% здоровья | маг; любой — против заклинателей |
| **Хитин** | 0.65 / 0.35 | сопротивление яду | −уклонение | универсал: держит и оружие, и магию |

Минусы материала не растут от качества, заточки и ранга. Вариации (5 на материал, у каждой свои названия для 4 слотов, см. `items-data.js`):
- латы: классика · тяжёлые (×1.2 защиты, ×1.5 минуса) · кольчужные (×0.85 защиты, минус вдвое меньше) · шипастые (шипы) · зачарованные (немного маг. защиты);
- кожа: уклонение · скорость · крит · точность · плотная (защита и здоровье);
- ткань: маг. атака · мана · интеллект · оберег (больше защиты обоих видов) · крит;
- хитин: классика · шипы · твёрдый (больше защиты от оружия) · сопротивление огню и холоду · здоровье за ход.

Пояса: пояс (здоровье), кушак (+маг. защита), ремень (+защита), перевязь (+крит), кошель (+золото). Амулеты: амулет, медальон (здоровье), кулон (крит. урон), талисман (удача и находка), ожерелье (защита и здоровье). Кольца: кольцо (удача), перстень (крит), печатка (здоровье), серьга (уклонение), браслет (обе защиты).

Проверка — `tools/armor.js`, полный отчёт по уровням 5…35 — `docs/BALANCE_ARMOR.md` (каждый класс × материал × вариация на уровнях 5…35 против всех архетипов монстров и босса). Итог балансировки: «свой» материал лучше для обычной охоты (латы — больше всего здоровья против физ. урона, ткань — маг убивает на треть быстрее, кожа — охотник быстрее); ткань и хитин — лучший ответ заклинателям (воин против лича на типичной экипировке: в латах ~50% побед, в хитине или ткани — все); латы на маге держат физических боссов, но бой длится в полтора раза дольше. Вариации внутри материала в пределах ±5 очков сводной оценки.

### 4.3 Редкость

| Редкость | Цвет | Аффиксов | Особое | Шанс (база) |
|---|---|---|---|---|
| Обычная | серый | 0 | — | 55% |
| Необычная | зелёный | 1 | — | 27% |
| Редкая | синий | 2 | — | 12% |
| Героическая | фиолетовый | 3 | — | 4.5% |
| Легендарная | оранжевый | 3 | + легендарное свойство | 1.2% |
| Мифическая | красный | 4 | + легендарное свойство, аффиксы не ниже T2 от потолка | 0.25% |
| Древняя | бирюзовый | 4 | + 2 легендарных свойства, все аффиксы в верхней половине диапазона | 0.05% |

Находка (`mf`) и боссы сдвигают распределение вверх. Боссы гарантируют минимум «Редкую».

### 4.4 Качество

Каждая вещь получает **качество 0–100%** → множитель базовых характеристик **×0.80…×1.20**. Ярлыки: Ветхое (0–19), Обычное (20–59), Добротное (60–84), Отличное (85–97), Безупречное (98–100). Качество не меняется — это отдельная ось охоты за «той самой» вещью.

### 4.5 Аффиксы

- Пул ~45 аффиксов. Каждый: на какие слоты падает, для каких классов (по типу базы), вес, **7 тиров** значений (T1 слабейший … T7 сильнейший), минимальный ilvl тира.
- Значение аффикса бросается внутри диапазона тира; на карточке видно `T5 · 63%` от максимума тира.
- Один аффикс не повторяется на вещи.
- Группы: атакующие (атака, крит, крит. урон, точность, скорость, стихийный урон, урон по типам врагов), защитные (защита, здоровье, блок, уклонение, сопротивления, снижение урона, шипы), ресурсные (мана, реген, вампиризм, перезарядка), утилитарные (опыт, золото, находка), **классовые** (+уровень конкретного умения, +% урона умения, +уровень всех умений класса — падают только на базы своего класса и на аксессуары с привязкой к классу).

### 4.5.1 Минусовые свойства (из EHT)

У Необычных, Редких и Героических вещей свойство с шансом 10% выпадает со знаком минус (−60% от значения). Такую вещь либо разбирают, либо перековывают у чародейки — это добавляет ценности перековке и «чистым» вещам.

### 4.6 Легендарные свойства

Уникальные эффекты, меняющие игру, у Легендарных и выше. Примеры:
- «Гром небесный» — 15% шанс при ударе ударить молнией на 80% атаки.
- «Неутолимая жажда» — вампиризм ×2, пока здоровье ниже 30%.
- «Эхо» — 20% шанс, что умение не уйдёт на перезарядку.
- «Щит из костей» — в начале боя щит на 15% здоровья.
- «Первая кровь» — первый удар в бою всегда критический.
- «Казнь» — +60% урона по целям ниже 25% здоровья.
- «Холодное сердце» — враги с заморозкой получают +30% урона.
- «Золотая лихорадка» — +50% золота, −10% защиты.

### 4.7 Заточка (+0…+15) и камни трёх рангов

| Уровень | Камень | Шанс успеха | При неудаче |
|---|---|---|---|
| +1…+5 | Камень заточки I | 100 → 80% | ничего |
| +6…+10 | Камень заточки II | 70 → 45% | −1 уровень заточки |
| +11…+15 | Камень заточки III | 35 → 12% | вещь ломается (свиток защиты спасает) |

- Каждый +1: +6% к базовым характеристикам.
- Вехи: **+5** — случайный аффикс повышается на тир; **+10** — вещь получает дополнительный аффикс; **+15** — все аффиксы повышаются на тир, имя вещи светится.

### 4.8 Ранг вещи ★0…★5

- Повышается у кузнеца: нужны **копия той же базы** (любой редкости) + эссенция + золото.
- Каждая ★ даёт +10% к базовым характеристикам и **поднимает потолок заточки**: ★0 → +5, ★1 → +7, ★2 → +9, ★3 → +11, ★4 → +13, ★5 → +15.
- Так дубликаты не бесполезны: любимую вещь кормят её копиями.

### 4.8.1 Знаки-добродетели и сеты (по мотивам «скрытых способностей» EHT)

- На ★3 вещь получает случайный **знак**: Справедливость (урон), Стойкость (здоровье и защита), Мудрость (магия), Ярость (криты), Удача (золото, находка, опыт).
- Надетые вещи с одинаковым знаком дают сетовый бонус за **2 / 4 / 6** вещей. Это главная долгая цель билда: собрать 6 вещей с нужным знаком и хорошими свойствами.

### 4.8.2 Перенос вложений (наследование из EHT)

- Заточку, ранг и знак можно перенести с одной вещи на другую того же вида (донор исчезает). Вложения не сгорают при переходе на более высокий тир — главный урок из отзывов об EHT.

### 4.9 Перековка (Чародейка)

- **Перебросить значение** одного аффикса (дёшево, тир не меняется).
- **Заменить аффикс** на случайный другой (дорого).
- **Замок**: зафиксировать аффиксы перед заменой (цена растёт за каждый замок).
- **Перековка качества**: новое случайное качество (может выйти хуже).
- Расходники: свитки перековки + эссенция.

### 4.10 Разбор и крафт

- **Разбор** вещи → руда / кожа / ткань / хитин (по материалу) **тира вещи** + эссенция (по редкости) + шанс камня заточки.
- **Ресурсы ковки с тирами** (T1…T7, тир = тир монстра или разобранной вещи; ковка вещи тира T требует ресурс тира T, эссенция без тиров):

| | T1 | T2 | T3 | T4 | T5 | T6 | T7 |
|---|---|---|---|---|---|---|---|
| Руда | Железная руда | Железный слиток | Стальной слиток | Рунный слиток | Мифрил | Драконья сталь | Древний металл |
| Кожа | Сыромятная кожа | Выделанная кожа | Дублёная кожа | Теневая кожа | Эльфийская замша | Драконья шкура | Древняя шкура |
| Ткань | Отрез ткани | Льняная ткань | Шёлк | Зачарованный шёлк | Звёздная парча | Драконий шёлк | Древнее полотно |
| Хитин | Хитиновые пластины | Жучиный панцирь | Роговые пластины | Скорпионий хитин | Королевский панцирь | Драконья чешуя | Древний панцирь |

  Прежние ресурсы без тира (`ore`, `leather`, `cloth`, `chitin`) стали T1.
- **Автоматический разбор** по фильтру (например, «всё ниже Редкой») — без этого гринд превращается в уборку.
- **Крафт у кузнеца** [MVP-минимум]: выбрать вид, материал (для брони), базу и тир (до открытой зоны), заплатить материалами → вещь с гарантированной редкостью не ниже Необычной. Целевой фарм нужной базы.
- Самоцветы и гнёзда, комплекты — [позже].

## 5. Умения и пассивки [MVP]

- У каждого класса **6 активных умений** (открываются на 1, 3, 6, 10, 15, 20 уровнях) и **8 пассивок**.
- **Очки умений**: 1 за уровень. Активное умение качается до 10 уровня, пассивка — до 5.
- В бою **4 ячейки умений** + обычный удар. Порядок ячеек = приоритет автобоя.
- Аффиксы «+N к умению» поднимают уровень сверх вложенного.

Пример (Воин): Удар щитом (оглушение) · Боевой клич (+атака) · Рассекающий удар · Стойкость (щит) · Возмездие (контратака) · Казнь. Пассивки: Закалка (+защита%), Мастер щита (+блок), Отпор (шипы), Второе дыхание (реген), …

## 6. Бой

- Пошаговый 1×1, лог в духе оригинала (хайку, падежи, цветные числа).
- Порядок — по скорости; при большом перевесе скорости бывает доп. действие.
- **Автобой**: умения по порядку ячеек, зелье при HP < 35%. Скорость проигрывания ×1 / ×2 / ×4. [MVP]
- Монстры имеют тип (зверь, нежить, гоблиноид, человек, конструкт), стихийные сопротивления и 1–2 умения.

### 7.1 Сложность мира (по мотивам Torment в EHT)

Цель — заставить гриндить статы и вещи, а не просто идти по монстрам.

| Сложность | Значок | Монстры (здоровье и атака) | Опыт и золото | Находка | Уровень вещей | Камни III |
|---|---|---|---|---|---|---|
| Обычная | I | ×1 | ×1 | — | — | — |
| Кошмар | II | ×2 | ×1.6 | +40% | +4 | 3% |
| Ад | III | ×4 | ×2.4 | +80% | +8 | 6% |
| Пытка I | IV | ×7 | ×3.4 | +130% | +12 | 10% |
| Пытка II | V | ×12 | ×4.6 | +190% | +16 | 15% |
| Пытка III | VI | ×20 | ×6 | +260% | +20 | 20% |
| Пытка IV | VII | ×32 | ×8 | +340% | +24 | 28% |
| Пытка V | VIII | ×50 | ×10 | +430% | +28 | 36% |

- Сложность одна на весь мир. Выбирается значком в шапке: цвет и анимация растут со ступенью (спокойный → пульс → пламя → кровь → ярость → бездна).
- Следующая ступень открывается победой над **последним боссом мира** (зона с `final: true`, сейчас Лич в Затопленном склепе) на текущей сложности. Когда появятся новые зоны, флаг `final` переносится на новую последнюю зону.
- Сложность **не гарантирует редкость**. Качество добычи зависит только от находки (сложность её повышает) и от уровня вещи.
- Защита монстров не растёт — иначе снижение урона росло бы как квадрат множителя.
- Вещь выше уровня своего тира сильнее: +4% к базе за каждый уровень предмета сверх уровня тира.
- Калибровка (tools/compare.js): случайная экипировка «Древних» +15 ★5 тянет Ад — Пытку II, идеальная — Пытку I–V.

### 7.2 Уники

Уник — именная вещь с фиксированными сильными свойствами и заметным минусом. Он вытаскивает один стиль игры или один тип противника, но не подходит везде.

- Падают только со «своего» босса. Некоторые — только начиная с определённой сложности. Шанс 4% на каждый уник, растёт с находкой.
- Тир уника растёт с уровнем предмета, поэтому уник с высокой сложности годен и в поздней игре. База ×1.25, 3 случайных свойства (как у героической вещи), заточка и ранги как обычно.
- Список и роли — `uniques` в items-data.js; эффекты в бою — engine.js.
- Замер: `node web/battle/tools/uniques.js [боёв] [фильтр]` — замена одной вещи легендарной сборки +10 ★3 на уник: против своего босса, обычного монстра и в «лучшем применении».

## 8. Интерфейс [MVP]

- **Тёмная тема** (фон #12141a, карточки #1b1e27), акцент — латунь, цвета редкостей как в 4.3.
- Нижняя навигация: **Мир · Герой · Сумка · Кузница**.
- **Герой**: «кукла» персонажа с 10 слотами, статы, распределение очков, умения и пассивки.
- **Сумка**: сетка 6×N ячеек, вещь — иконка в рамке цвета редкости с бейджами (+заточка, ★ранг). **Drag & drop** мышью и пальцем (Pointer Events): из сумки на слот куклы — надеть, со слота в сумку — снять, на корзину — разобрать. Тап — карточка вещи со сравнением с надетой. Фильтры и сортировка.
- Карточка вещи: рамка редкости, качество, базовые статы, аффиксы с тиром и долей от максимума, легендарные свойства, заточка/ранг, сравнение «+/−» с надетым.
- Графика: свой стиль, тёмное фэнтези, плоский вектор (`web/battle/assets/`).
