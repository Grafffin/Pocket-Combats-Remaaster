# Обмен между игроками

Статус: сервер и правила готовы (миграция 0017, `web/battle/js/trade.js`), интерфейс — следующим PR.

## Как устроено

Сделка — строка `game_trades` (миграция `0017_trade.sql`). Два игрока на одной локации: `a` приглашает, `b` принимает.
Предложенное (до 8 ячеек: вещи из сумки и стаки ресурсов, плюс золото) **уходит из героя в залог** (`offer_a`, `offer_b`)
и до конца сделки больше нигде не лежит. Поэтому второй раз продать, потратить или предложить в другую сделку нельзя.

Операции (`tradeOpen`, `tradeAccept`, `tradeOffer`, `tradeConfirm`, `tradeUnconfirm`, `tradeCancel`, `tradeClaim`) идут
через функцию `game`. Все данные берутся из героя на сервере; клиент присылает только `uid` вещей, id ресурса и число.
Запись героя и сделки — одна SQL-транзакция `trade_commit` с проверкой версии сделки (`ver`) и героя (`rev`).

## Что закрыто (тест `tools/trade-test.js`)

| Схема | Защита |
|---|---|
| Подменить предложение после «подтвердил» | любая правка бросает подтверждения; `tradeConfirm` действует только на `ver`, который игрок видел |
| Подтвердить вслепую в момент правки | сравнение `ver` в аргументах и CAS по версии строки в транзакции |
| Предложить чужую / выдуманную / надетую / запертую вещь | вещь ищется в сумке самого героя, запертая отклоняется |
| Одну вещь дважды, один ресурс дважды | дубли отклоняются |
| Золота или ресурсов больше, чем есть; дробные, отрицательные, строки, NaN | целые от 0 до 1e9 и не больше, чем у героя |
| Продать или потратить предложенное в обход | предложенное уже вынуто из героя |
| Вмешаться в чужую сделку | `a`/`b` только; остальные получают `not_yours` |
| Две сделки сразу, обмен с собой | `trade_create` с advisory-локом; один открытый обмен на игрока |
| Забрать дважды | флаги `claimed_a/b`, повторный сбор ничего не выдаёт |
| Отмена после завершения, правка после отмены | операции только над `open` |
| Нет места в сумке | сделка не закрывается; место проверяется у обоих до завершения; сбор можно повторить |
| Уйти с локации посреди сделки | подтверждение требует обоих на локации сделки; отмена и сбор доступны всегда |
| Зависшая сделка | через 15 минут считается отменённой, залог возвращается при сборе |
| Пустая сделка | запрещена |

Сохранение массы (золото, uid вещей, ресурсы) проверяется после каждого сценария.

## Ограничения

- Игрок, который не заходит, не получит залог, пока не зайдёт (клиент собирает при входе).
- Сумма золота в предложении не больше 1 млрд.
