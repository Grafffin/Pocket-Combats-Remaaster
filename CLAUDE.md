# Pocket Combats Remaster — правила для сессии

Веб-ремейк мёртвой MMORPG Pocket Combats. Чистый JS без сборки, клиент на GitHub Pages (`web/battle/`), бэкенд Supabase (Postgres + Auth + Realtime + Edge Function `game`). Экран мобильный, 375×812, графика своя (SVG).

**Перед работой прочитай `docs/HANDOFF.md`** (структура, архитектура, тесты, деплой, открытые вопросы). Детали: `docs/PROJECT_CONTEXT.md`, `docs/GDD.md`, `docs/SERVER_AUTHORITY.md`, `docs/ONLINE_ARCHITECTURE.md`, `docs/BACKLOG.md`.

## Правила

- Общайся по-русски. Коммиты, комментарии в коде и PR — по-русски, комментарии в плотности окружающего кода.
- Дроби задачу на мелкие PR, читай только нужные файлы, без лишних обзоров (экономия токенов).
- PR можно мерджить самому после своей проверки (тесты зелёные). Спрашивай только критичное: ключи, аккаунты, платные действия, удаление данных, SQL на боевой Supabase.
- SQL-миграции на боевой базе применяет пользователь в Supabase → SQL Editor (можно с телефона). Ты только пишешь файл `supabase/migrations/NNNN_*.sql` с инструкцией в шапке. `service_role` ключ не проси и не храни.
- Новое действие героя вне боя добавляй ТОЛЬКО в `web/battle/js/actions.js` (после миграции 0014 клиент не может писать героя, иначе действие не сохранится).
- Не ломай детерминизм боя (`engine.js`, `lockstep.js`): после правок гоняй тесты из HANDOFF §6.
- Балансные правки проверяй симуляторами (`sim.js`, `compare.js`, `uniques.js`), а не на глаз.
- Никаких ключей и токенов в репозиторий (anon key публичный и уже в `config.js`, это нормально).
- Не добавляй зависимости и сборку. Не храни оригинальный APK и файлы CDN.
- Любой новый видимый текст пиши по-русски в коде и сразу добавляй английский перевод в `web/battle/js/lang/en-*.js` (ключ — русский текст, подстановки `{}`); `node web/battle/tools/i18n-test.js` проверяет перевод данных и токены боя. Данные игры остаются русскими (одни и те же у всех игроков и на сервере), переводится только показ: `js/i18n.js`.
